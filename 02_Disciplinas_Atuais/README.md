# Disciplinas Atuais

Material das disciplinas cursadas, separado por semestre.

O nível de semestre existe porque o curso tem oito. Sem ele, esta pasta viraria
um depósito já no semestre seguinte.

## Semestres

- [`1_Semestre`](1_Semestre) — Bootcamp I · Banco de Dados I · Engenharia de
  Software · Fundamentos da Engenharia · Introdução à Computação · Lógica de
  Programação

## Como cada disciplina se organiza

Toda disciplina tem `Materiais_Didaticos`, com o que o professor disponibiliza.
A partir daí:

- **Disciplina teórica** acrescenta `Atividades_e_Entregas` e
  `Anotacoes_e_Resumos`
- **Disciplina de projeto** acrescenta as etapas de entrega, como acontece no
  Bootcamp I
