# Projetos e Certificados

Produção que não pertence a uma disciplina específica.

## Estrutura

- [`Projetos`](Projetos) — projetos pessoais, um por pasta
- [`Certificados`](Certificados) — certificações e cursos concluídos

Cada projeto tem a própria pasta, com um `README.md` explicando o que é, que
decisões foram tomadas e como executá-lo.
